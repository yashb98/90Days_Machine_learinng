

# 📘 Gemini RAG PDF Q&A System

A **Retrieval-Augmented Generation (RAG)** system that allows you to upload a PDF, split it into chunks, and query it using Google Gemini LLM. Built with **Python**, **ChromaDB**, and **Gradio** for an interactive interface.

---

## Features

- Upload PDF documents and automatically split text into chunks.
- Store chunks in a **ChromaDB vectorstore** with embeddings for fast retrieval.
- Ask questions about the PDF and get context-aware answers.
- Retrieve the top-K most relevant chunks as sources for each answer.
- Interactive web UI powered by **Gradio**.

---

## Tech Stack

- **Python 3.12**
- **ChromaDB** for vector storage
- **Google Gemini API** for LLM generation
- **LangChain text splitter** for PDF chunking
- **PyPDF2** for PDF reading
- **Gradio** for UI

Installation
	1.	Clone the repository:

git clone <your-repo-url>
cd <repo-folder>

	2.	Create a virtual environment and activate it:

python -m venv venv
source venv/bin/activate  # macOS/Linux
venv\Scripts\activate     # Windows

	3.	Install dependencies:

pip install -r requirements.txt

	4.	Set your Google API Key in a .env file:

GOOGLE_API_KEY=your_google_gemini_api_key


⸻

Usage
	1.	Launch the Gradio app:

python app.py

	2.	Open the local URL provided by Gradio in your browser.
	3.	Upload a PDF file. The system will:
	•	Split it into chunks
	•	Store them in ChromaDB
	•	Make it ready for querying
	4.	Ask questions about the PDF. The system returns:
	•	An answer generated by Google Gemini LLM
	•	Top-K source chunks with page and chunk numbers
